# Народы России

Статический сайт о культуре, традициях, кухне, истории и народных играх народов России.
Основной раздел проекта — народы Кузбасса.

## Страницы

- `index.html` — главная страница, блок «Народы Кузбасса»;
- `traditions.html` — традиции народов: праздники, орнаменты, обычаи;
- `cuisine.html` — кухня народов: интерактивные карточки рецептов;
- `history.html` — история народов;
- `games.html` — народные игры.

## Ветки

- `main` — стабильная версия сайта;
- `dev` — общая ветка для сборки изменений;
- `Dima`, `Egor` — личные ветки участников.

Работаем в своей ветке, готовые изменения вливаем в `dev`.

## Запуск

Сборка не нужна: откройте `index.html` в браузере.

## Стили

Общий стиль сайта — `css/style.css`. Файл закреплён за Иваном: остальные участники его не редактируют, чтобы не создавать конфликтов. Подробнее — в `AGENTS.md`.

`css/history.css` — рабочий стиль раздела «История народов». Все правила с префиксом `.hist`, файл можно удалить целиком, когда появится общий дизайн.

## Мини-игры

`games.html` — пять мини-игр, по одной на народ. Переключение народов сделано на CSS по якорям, как в разделе истории.

- `css/games.css` — переключатель народов и общий каркас панелей (префикс `.mg`);
- `css/games/<народ>.css` — стиль отдельной игры (`.mg-sh`, `.mg-arch`, `.mg-race`, `.mg-tag`, `.mg-gor`), файл можно удалить вместе с игрой;
- `js/games/<народ>.js` — логика отдельной игры; скрипт сам находит свой блок и молча выходит, если блока на странице нет.

Игры не зависят друг от друга и не трогают общий `css/style.css`.
