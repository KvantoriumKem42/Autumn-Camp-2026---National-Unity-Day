# AGENTS.md

Правила для AI-агентов, работающих с этим репозиторием.

## О проекте

Статический сайт «Народы России» о культуре народов Кузбасса. Чистый HTML и CSS, без сборщиков и JavaScript.

## Владение файлами

- `css/style.css` — зона ответственности Ивана. Не изменяй этот файл в задачах по другим разделам, не переформатируй его и не добавляй стили «заодно». Любые правки — только по прямой просьбе владельца.
- Остальные файлы можно менять в рамках своей задачи. Не удаляй чужие разделы и не переписывай их без необходимости.
